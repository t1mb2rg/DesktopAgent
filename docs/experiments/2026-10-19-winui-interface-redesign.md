# WinUI 界面重设计首版

日期：2026-10-19

## 方向与范围

用户明确选择保留底层、重新设计界面，视觉方向为简洁原生工具：克制、清晰、接近 Windows 应用。

本轮重排主窗口导航、首页、设计库工作台和 AI 助手。设计库采用常驻左侧设计库与模板列表、中间桌面画布、右侧属性编辑的结构；准备、编辑、预览与应用仍有明确入口。保存和取消编辑放在属性面板顶部，应用动作与预览状态放在画布下方。工作区详情不会再隐藏设计库。

窄工作台宽度下，属性编辑器改为画布下方可滚动区域；这一路径已实现，但本轮窗口边缘拖动未成功改变实际窗口大小，因此不记为真实窄窗口验收通过。

AI 助手提供独立多行输入区，弱化实现术语，说明分析、设计、预览和确认应用的关系。首页主入口统一为“打开设计库”。

修复两个导航问题：从准备页新建模板后立即进入编辑页；载入冻结工作区预览后进入预览与应用页。执行、恢复、权限和校验逻辑沿用现有路径。
