# M1-01：任意数量显示器拓扑读取

## 目标

验证 Windows 11 环境中能否可靠读取：

- 显示器数量；
- 主屏标记；
- 虚拟桌面坐标；
- 工作区坐标；
- DPI 与缩放；
- 负坐标。

## 当前实现

`NativeDisplayTopologyReader` 使用：

- `EnumDisplayMonitors`
- `GetMonitorInfo`
- `GetDpiForMonitor`

PoC 界面会列出所有显示器。该实验只读取信息，不会修改任何桌面图标或文件。

## 人工验收

- [ ] 两屏环境数量正确
- [ ] 三屏环境数量正确
- [ ] 左侧显示器坐标为负时读取正确
- [ ] 不同 DPI 缩放读取正确
- [ ] 主屏标记正确
- [ ] 断开/重新连接显示器后点击“重新读取”结果正确
