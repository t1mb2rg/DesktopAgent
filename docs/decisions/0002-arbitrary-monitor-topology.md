# ADR-0002：底层支持任意数量显示器

- 状态：已接受
- 日期：2026-07-19

## 决策

从首个 PoC 开始，底层不得假设用户只有一块或两块显示器。所有坐标使用 Windows 虚拟桌面的物理像素坐标，并允许负坐标。

M1 只修改用户明确选择的一块目标显示器；其余显示器只读。

## 原因

显示器可能位于主屏左侧、右侧、上方或下方，连接顺序与系统编号也可能变化。若早期把坐标系统写死为双屏或正坐标，后续三屏适配会造成结构性返工。

## 后续

正式版将补充比 `\\.\DISPLAYx` 更稳定的设备身份识别，并支持显示器断开时临时迁移到主屏、重新连接后恢复原布局。
